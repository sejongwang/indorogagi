# indoro

인도 약국을 진입점으로 삼는 복약 안내 서비스. 약사가 수기 처방전을 앱에 입력하면(항목당 20~40초 목표), 서버가 토큰 URL과 QR을 발급하고, 환자는 앱 설치 없이 폰으로 QR을 스캔해 저문해 친화적인 복약 인포그래픽(힌디/영어)을 본다.

2026 아이디어 해커톤 인도 해외연수 지원 프로젝트 — KAIST 팀(김나연 · 김준휘 · 정영민).

> **개발 단계 프로토타입입니다.** 실제 환자에게 배포된 의료 서비스가 아니며, 데이터·약국 정보는 모두 데모용 가공값입니다.

## 이게 뭘 푸는가

인도 외래 진료는 평균 약 2분이라 복약 설명이 생략되고, 수기 처방전은 라틴 약어("1-0-1", "TDS")로 쓰여 환자가 해독하기 어렵다. 문해율이 낮은 계층과 22개 공용어 환경에서 "언제 무엇을 얼마나 먹는가"가 환자에게 전달되지 못한다. indoro는 약사를 진입점으로 이 마지막 구간을 그림·숫자·색으로 메운다.

## 빠른 시작

### 서버 (관통 프로토타입)

[uv](https://docs.astral.sh/uv/)가 필요하다.

```bash
cd server
uv sync                              # 의존성 설치
uv run python scripts/seed_import.py # 의약품 시드 627건 임포트
uv run python scripts/demo.py        # 데모 처방 1건 생성 → 열람 URL 출력
uv run uvicorn app.main:app --port 8600
```

- 약사 처방 입력: http://127.0.0.1:8600/rx/new
- 환자 인포그래픽: `demo.py`가 출력한 `patient URL` (뒤에 `?lang=en`으로 영어)
- 테스트: `uv run pytest -q`

> 폰으로 QR을 실제 스캔하려면 `--host 0.0.0.0`으로 띄우고 폰에서 `http://<이 PC의 LAN IP>:8600/rx/new`로 접속한다. QR은 요청 호스트 기준으로 URL을 인코딩하므로 `127.0.0.1`로 띄우면 폰에서 열리지 않는다.

### 와이어프레임 (정적 화면)

```bash
python3 -m http.server 8493 --directory wireframes
# http://127.0.0.1:8493/index.html — 화면 허브
```

## 현재 상태

인도 방문 전 원격으로 가능한 트랙을 완료한 상태다.

- **설계·와이어프레임**: 완료. S1 환자 화면은 약×시간 매트릭스 + 복용량 픽토그램 인포그래픽.
- **의약품 시드**: 627건, 3단계 검증 완료(스팟체크 + 다성분 OTC 전수 재검증 + 금지 FDC 제거).
- **서버 프로토타입**: 관통 동작(pytest 통과). 인포그래픽 파이프라인 실동작.
- **의도적 미구현(현지/후속 트랙)**: 패턴별 프리렌더 영상·음성 실파일, 완전한 오프라인 큐, 일부 운영 화면(온보딩·목록·수정 UI), 배포. 서버의 [`README.md`](server/README.md)에 범위표가 있다.

다음: 팀 리뷰 → 파일럿 지역(1차 언어) 확정 → 현지 사용자 테스트.
