# 현장 조사 계획서 인덱스

> **자리표시자 유지**: 조사 지역 **[도시·주·병원 또는 약국 유형 입력]**(권장 기본값 예시: 우타르프라데시 러크나우 등 힌디 벨트 Tier-2 도시), 조사 인원 **[예상 인원 입력]**(권장 기본값 예시: 총 28~38명)은 [01 문서 §2.1~2.2](01-goals-participants-screener-consent.md)에서 확정한다.

## 1. 이 조사 계획서가 결정하려는 것

이 계획서는 indoro의 핵심 가설 H1~H6 — 수기 처방·봉투 표기만으로는 복약 이해가 어렵다(H1), 숫자·색·아이콘 결합 화면이 저문해 환자를 돕는다(H2), 무설치 QR 접근이 현장에서 작동한다(H3), 약국 발급 링크를 환자가 신뢰한다(H4), 약사 입력 20~40초가 현실적이다(H5), 가족·보호자 열람이 필요하다(H6) — 를 인도 약국·병원 현장에서 검증한다. 호감도 확인이 아니라 현재 행동·실제 발생한 혼란·약사의 업무 흐름·기기와 언어 제약을 근거로, 환자 화면 정보 우선순위·입력 폼 필수 필드·QR 발급 경로·백업 코드 노출·링크 만료 소통·공유 기능 우선순위 등 [01 문서 §1.1](01-goals-participants-screener-consent.md)에 정의된 제품 결정을 내린다. 조사가 끝나면 [11 문서 섹션 15](11-analysis-codes-pilot-criteria.md)의 임계값에 따라 파일럿 진행·보류·중단을 판정한다.

## 3. 현장 하루 운영 순서

| 단계 | 하는 일 | 사용 문서 |
|---|---|---|
| 1. 도착 | 게이트키퍼 허가 재확인, 직원 고지 스크립트 낭독, 관찰 위치 선정 | [08](08-observation-checklist.md) §2.4 |
| 2. 관찰 | 환경 스냅숏(O1~O4 / 병원 O15·O16·O22·O24) → 30분 탈리 블록 반복. 피크 1·비피크 1 세션 권장 | [08](08-observation-checklist.md) §3~§7 |
| 3. 인터셉트 | 관찰과 병행·교대로 대상자 접근, 스크리너 S1~S13으로 대상군 판별·쿼터 확인 | [01](01-goals-participants-screener-consent.md) §3 |
| 4. 동의 | 동의 안내문 낭독, 참가자 코드 부여. 실제 처방전·개인정보는 수집하지 않는다 | [01](01-goals-participants-screener-consent.md) §4, 부록 A |
| 5. 인터뷰 | 대상군별 질문지 진행 — 환자 10~15분, 약사·병원 관계자 20~30분. 프로토타입은 인터뷰 후반까지 보여주지 않는다 | [02](02-questionnaire-patient.md)~[07](07-questionnaire-hospital-ops.md) 중 해당 문서 |
| 6. 프로토타입 | 환자·보호자 T-P1~T-P9, 약사 T-PH1~T-PH7 시연·과업 + 후속 질문 W5~W12. 저문해 참가자는 teach-back 프로토콜. 간호사는 W-N2 동의 시 06 문서 [N18] 시연 스크립트로 진행(의사 D14·원무 H14는 각 질문지 E 구간 내 시연) | [09](09-prototype-usability-tasks.md), [06](06-questionnaire-nurse.md) N18 |
| 7. 종료 | 종료 질문 W13~W16, 사례품 전달, 노트 시트 NT 마감 | [10](10-closing-notes-debrief.md) 섹션 11~12 |

## 4. 인쇄·준비물 체크리스트

출발 전 [13 문서 §6](13-risk-review.md) 상위 5개 위험 해소를 먼저 확인한다.

**인쇄물**

- [ ] 스크리너·동의 안내문(01 §3~§4) — 진행자 수만큼
- [ ] 대상군별 질문지 인쇄본(02~07) — 당일 쿼터에 맞게
- [ ] 관찰 체크리스트 + 30분 탈리 시트 여분(블록 수 + 2장), 병원 세션은 O17 세션 단위 기록표 1장 추가(08 §7)
- [ ] 과업 기록 시트(09 §5.2), 숫자 자신감 카드(1~5 + 얼굴 픽토그램)
- [ ] 노트 시트 2종(환자·보호자판 / 약사판 — 대상군별 참가자 수 + 20%), 디브리프 시트 동수(10 부록 B)
- [ ] 소개 카드(W14용), 연락 동의서(W15 직원용 — 노트와 다른 색 종이, 환자·보호자용은 만들지 않음), 쿼터 시트(당일분), 질문지 변경 로그 양식
- [ ] 현장 태깅 치트시트(11 부록 B — 인쇄용 반쪽), 현장 유형 코드표, 01 §4.5 대응 문구 카드

**프로토타입·기기**(09 §3)

- [ ] 시연 QR 카드 A(유효 링크) · B(만료 링크, 410 화면 확인)
- [ ] 연구용 스마트폰 1대 — 데이터 연결·밝기 최대·알림 차단
- [ ] 약사 시연 기기 — 시연 전용 약국 계정으로 입력 화면 접속 확인
- [ ] 연습용 처방전 카드, 봉투 소품 3장(번호 1·2·3 기입), 시나리오 카드(T-PH7)

**공통·운영**

- [ ] 클립보드 2개, 필기구 2자루, 폰 스톱워치(랩 기능)
- [ ] 사례품(01 §2.3-4 규정)
- [ ] 통역자 브리핑 완료 — 13 §5 통역 왜곡 위험 표현 목록으로 사전 리허설
- [ ] 힌디 문구 원어민 검수 완료 확인(아래 언어 정책)

## 5. 언어 정책 요약

- **한국어**: 연구자용. 진행 규칙·기록 지침·분석 도구 등 문서 본문은 모두 한국어다.
- **쉬운 영어**: 현장 기본. 참가자에게 읽는 모든 문장은 쉬운 영어 버전을 기본으로 낭독한다.
- **힌디 초안**: 참가자에게 읽는 힌디 문장은 전부 초안이며 **현지 원어민 검수 후에만 사용한다**. 데바나가리 표기·존칭·지역 어휘(दोपहर/शाम/रात 구분)와 성별 일치(진행자·응답자 두 축)를 검수에서 확정하고, 조사 지역이 바뀌면 해당 지역어 기준으로 전량 재검토한다([13 문서 §5](13-risk-review.md)).
- **예외**: 12 문서는 힌디 문장이 없는 연구팀 내부 도구라 힌디 초안 규칙을 적용하지 않는다. 13 문서는 질문 문안 형식(3언어 병기)은 적용하지 않되, §5.2 통역용 고정 역어는 통역자가 참가자에게 낭독하는 문구이므로 원어민 검수 후 확정한다([13 문서 §5.2](13-risk-review.md)).
- 지역어(비힌디) 참가자는 통역을 통해 진행하며, 통역자는 13 §5 브리핑을 마쳐야 한다.
