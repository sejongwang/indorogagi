# 질문별 목적과 결정할 제품 요소 — 통합 매핑

> **이 문서에는 힌디 초안이 없다.** 참가자에게 읽는 문장이 없는 연구팀 내부 참조 도구이므로, 힌디 초안 필수 규칙의 적용 대상이 아니다. 각 질문의 실제 문구·힌디 초안·진행 규칙은 원 질문지 문서(02~10)를 따른다.

- 결과물 섹션 16: **질문별 목적과 해당 질문으로 결정할 제품 요소** — ① 대상군별 전체 매핑 표, ② 가설 H1~H6별 역매핑(지지/반박 시 제품 결정), ③ 제품 요소별 역매핑, ④ 커버리지 공백.
- 조사 지역: **[도시·주·병원 또는 약국 유형 입력]** — 권장 기본값 예시: 우타르프라데시 러크나우 등 힌디 벨트 Tier-2 도시([01 문서 §2.1](01-goals-participants-screener-consent.md)).
- 조사 인원: **[예상 인원 입력]** — 권장 기본값 예시: 총 28~38명([01 문서 §2.2](01-goals-participants-screener-consent.md)).
- 위치: 이 문서는 02~10 문서에 흩어진 질문·과업·관찰·노트 항목과 (가설, 제품 결정)의 대응을 한 곳에 모은 **인덱스**다. 판정 절차와 임계값은 [11 문서](11-analysis-codes-pilot-criteria.md), 목표–가설–결정의 원 정의는 [01 문서 §1.1~1.3](01-goals-participants-screener-consent.md), 제품 결정의 등록처는 [01-dataflow.md](../01-dataflow.md) 결정 레지스터다.
- 참조: [01](01-goals-participants-screener-consent.md) 스크리너 S / [02](02-questionnaire-patient.md) 환자 P / [03](03-questionnaire-caregiver.md) 보호자 C / [04](04-questionnaire-pharmacist.md) 약사 PH / [05](05-questionnaire-doctor.md) 의사 D / [06](06-questionnaire-nurse.md) 간호사 N / [07](07-questionnaire-hospital-ops.md) 원무 H 문항 / [08](08-observation-checklist.md) 관찰 O / [09](09-prototype-usability-tasks.md) 과업 T-P·T-PH / [10](10-closing-notes-debrief.md) 종료 W·노트 NT·디브리프 DB.
- 표기 주의([11 문서](11-analysis-codes-pilot-criteria.md)와 동일): 병원 원무 질문 ID(H1~H20)와 핵심 가설(H1~H6)의 접두어가 겹친다. 이 문서에서 가설은 **"H#"를 가설 열·가설 문맥에서만** 쓰고, 병원 질문은 항상 **"H# 문항"** 으로 쓴다.
- 게이트 5(파일럿을 막는 운영·문화·기술 위험, [01 문서 §1.3](01-goals-participants-screener-consent.md))는 가설이 아니라 별도 판정 축이다. 해당 항목은 §2.7에 모아 둔다.

**중복 제거·정리 내역** (원 조각 대비 변경점):

1. **T-PH1~T-PH7·W10~W12**는 04 문서 조각과 09 문서 조각에 중복 수록되어 있었다 → §1.10 하나로 통합. 요약·필수 여부는 09 문서(원 정의) 기준으로 통일하고, 가설·결정 요소는 두 조각의 합집합으로 기록했다(세부 귀속은 §1.10 비고).
2. 04 문서 조각의 **O(PH12 연계)·O(규칙5)** 두 행은 08 문서 관찰 항목의 연계 표시였다 → §1.8의 O2(기기·인프라 인벤토리)와 08 문서 관찰 규칙 5(자연 응대 장면 — O9·O10·O14 탈리로 계량)에 흡수(§1.8 비고). PH12 답변↔O2 관찰의 대조 기록 의무는 유지된다.
3. 환자 질문지의 **P8-③(구 P9)·P11-③(구 P15)** 는 구번호를 비고로 유지한 채 현행 ID로만 수록. P9·P15라는 독립 행은 존재하지 않는다.
4. 정렬은 대상군 내 ID 순이다. 실제 진행 순서와 다른 항목(예: S8a는 ID상 S8 다음이지만 실제로는 S10 직전 하드 게이트)은 행 안에 명시했다.

## 2. 가설 H1~H6별 역매핑

**공통 항목**: 다음 6개는 모든 가설(H1~H6)에 걸치는 판정·수집 장치라 각 가설 목록에서 제외하고 여기 한 번만 적는다 — **S1, D15, H15 문항, W13, NT5, DB2**. 이 항목들은 개별 가설의 증거를 만드는 게 아니라, 트랙 분기(S1), 프레이밍 없는 첫 반응(D15·H15 문항), 미발견 이슈(W13), 참가자·일 단위 판정 원장(NT5·DB2)으로 **모든 가설의 판정 절차**를 받친다.

표기: (맥락) = 해당 가설의 직접 증거가 아니라 배경·맥락 확인용. (유사) = 간호 업무의 유사 부담·유사 흐름으로 H5(약사 수용성)를 간접 검증. 지지/반박 판정 신호의 원 정의는 [01 문서 §1.2](01-goals-participants-screener-consent.md), 임계값과 절차는 [11 문서 §3](11-analysis-codes-pilot-criteria.md).

### 2.1 가설 H1 — 짧은 표기만으로는 환자가 복약 방법을 정확히 이해하기 어렵다

**검증 질문 (48개)**

- 관찰: O7 O8 O9 O10 O11 O16 O18 O19 O20
- 과업: T-PH3(맥락)

**지지 시 결정** ([01 문서 G1](01-goals-participants-screener-consent.md))
1. 파일럿 전제(문제 실재성) 성립 — 게이트 1 통과.
2. 환자 화면 정보 우선순위 v1 확정 — 실측 혼동 빈도 상위 항목(식전후/기간/용량/시간대 — PH8·N5·O10·D9 분포 기준)을 최상단 배치.
3. 봉투 숫자 번호 체계 채택 유지(P4·O11 근거).

**반박 시 결정**
1. 파일럿 전면 보류가 아니라 타깃 세그먼트(저문해·고령·다제복용)를 좁혀 문제 실재성 재검토 — 스크리너 쿼터(S4·S7·S8) 조정 후 재조사.
2. 환자 화면의 포지셔닝을 "표기 해독 보조"에서 "재열람·가족 공유 보조"로 이동(H6 결과와 연동).
3. 봉투 번호 체계가 기존 표기와 중복 부담이면 간소화 검토.

2. 아이콘+짧은 라벨+숫자 계약 확정 — 오독된 개별 아이콘만 교체(W9·DB4 수정 목록).
3. 힌디 시간대 어휘 확정(सुबह/दोपहर/शाम/रात, 취침 전 표현 — DB5 교차).

**반박 시 결정**

4. 저문해 환자 단독 이해 대신 보호자 경유 흐름(H6 연계)으로 설계 무게 이동.
