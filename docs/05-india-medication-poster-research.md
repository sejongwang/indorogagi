# 인도 복약 포스터 레퍼런스 조사

- 조사 목적: 저문해 사용자가 작은 Android 화면에서 복약 행동 순서를 빠르게 찾는 환자 화면 설계
- 접근일: 2026-07-10
- 범위: 인도 정부 IEC, 인도 복약 표기·이해도 연구, 데바나가리·모바일 접근성 자료
- 근거 상태: **SUPPORTED**는 출처의 직접 관찰, **DERIVED**는 그 관찰에서 도출한 설계 판단, **GAP**은 현지 사용자 검증이 필요한 가설이다.

## 결론

환자 첫 화면은 약별 표가 아니라 **A안: 하루 시간 흐름 포스터**로 구성한다. `아침 → 점심 → 저녁 → 밤`을 한 방향으로 고정하고, 각 시간대에 봉투의 **색 + 큰 번호**, 약명, 용량, 식전·식후 순서를 함께 반복한다. 약별 상세정보와 공유 등 보조 행동은 이 흐름 아래에 둔다.

이 방향은 인도 공공보건 IEC의 큰 행동 문구·현지어 병기, 실제 복약 연구의 숫자·약어 혼동, 그림과 설명을 함께 제공했을 때의 이해도 개선을 반영한다. 다만 정부 포스터는 대중 캠페인용이고, 개별 처방 화면 자체에 대한 전국적 민속지 자료는 아니다. 따라서 아래 구현 원칙은 근거 기반 설계안이며 임상·현장 검증의 대체물이 아니다.

## 현지 시각 문법의 적용 범위

### 직접 채택

- **행동 우선 위계:** 상단에 약국 신뢰 정보와 “오늘 이렇게 드세요” 같은 한 문장, 그 아래에 복용 순서를 둔다.
- **고정된 하루 흐름:** `아침 → 점심 → 저녁 → 밤`의 시각 순서와 DOM 순서를 언어에 관계없이 유지한다.
- **중복 단서:** 시간대마다 자체 SVG + 짧은 시간 라벨을 함께 쓰고, 약은 색뿐 아니라 큰 봉투 번호와 약명을 반복한다.
- **그림 + 말 + 숫자:** 용량은 `½ 정`, `5 ml`, `2 방울`, `1 캡슐`처럼 그림 옆에 수치와 단위를 풀어 쓴다.
- **식사 순서 자체를 그림으로 표현:** `알약 → 접시`와 `접시 → 알약`처럼 순서를 보여주되 각각 `식전/Before food`, `식후/After food` 라벨을 병기한다.
- **가벼운 다언어 화면:** 핵심 복약 정보는 서버 HTML에 모두 렌더링하고, JavaScript·음성·영상 없이도 읽히게 한다.

### 참고만 하고 그대로 복제하지 않을 요소

- 공공보건 포스터의 따뜻한 종이색, 강한 제목 대비, 짧은 슬로건, 가족·보건요원 삽화는 분위기와 위계만 참고한다.
- 캠페인의 다채널 방식은 공유·음성·영상의 필요성을 뒷받침하지만, 이 기능들은 핵심 복약 흐름 아래에 둔다.
- 상용 약 봉투의 이중언어 시간대 어휘는 참고할 수 있으나, 한 판매자의 상품이 인도 전역 표준이라는 근거는 아니다.
- 대형 인쇄 포스터의 빽빽한 정보량과 여러 장식 구획을 320px 화면으로 옮기지 않는다.

### 저문해 사용자에게 혼란을 줄 수 있는 요소

- `1-0-1`, `x-o-x`, `OD`, `BD`, `TDS`, `HS`, `AC`, `PC`, `PRN`을 설명 없이 노출하는 것
- 해·달·접시·알약·색상 또는 화살표만으로 시간, 약, 식전·식후를 전달하는 것
- 기기마다 모양이 다른 이모지, 실제 알약 사진, 장식적인 의료 아이콘을 식별 수단으로 쓰는 것
- 가정용 티스푼을 ml 단위처럼 보여주거나, `반 알`을 그림만으로 표시하는 것
- PRN/SOS를 최소 복용 간격·일일 최대량 없이 “필요 시”로만 쓰는 것
- 실제 복용 확인 데이터 없이 “다음 약”, “완료”라고 단정하는 것
- 긴 약명·힌디 문장을 말줄임표, 고정 높이, 임의 음절 분리로 자르는 것

### 저작권·브랜드 때문에 복제하지 않을 요소

- 인도 정부 문장, MoHFW/NHM/NCDC 로고, 인도 국가문장, 캠페인 로고·슬로건·사진·삽화
- 공공병원이나 특정 약국의 명칭·상표·유니폼·시설 사진을 이용한 제휴 암시
- 상용 약 봉투의 사진, 그래픽 배열, 상표와 트레이드 드레스
- 출처가 불명확하거나 라이선스가 없는 의료 픽토그램 세트

시간대, 접시, 알약, 달력, 용량 표시는 단순한 **자체 제작 SVG**로 만들고 텍스트 라벨을 붙인다. 정부 또는 의료기관의 승인을 받은 화면처럼 보이게 하지 않는다.

**선택: A. 하루 시간 흐름 포스터.** 우선순위 1·2인 오류 감소와 첫눈 이해에 더 직접적이고, 기존 M/N/E/H 순서를 그대로 보존한다. A안의 약점인 봉투 연결은 모든 시간대 항목에 같은 **색 + 큰 번호 + 약명**을 반복해 보완한다. 약별 상세는 핵심 흐름 뒤의 네이티브 `details`에 두되, 핵심 용법은 이미 위에 서버 렌더링해 JavaScript가 없어도 보이게 한다.

`3초 안에 찾기`는 이 정보 위계가 지향하는 시험 목표이지, 현재 문헌만으로 입증된 결과는 아니다. 실제 저문해 사용자 관찰로 검증해야 한다.

## 구현에 반영할 규칙

1. 첫 화면은 제목 다음에 하루 시간 흐름을 시작하고, 약별 상세·기간·가족 공유·음성·영상은 그 뒤에 둔다.
2. 시간대는 항상 아침(M)·점심(N)·저녁(E)·밤(H) 순서다. 데이터가 없는 시간대도 순서의 기준을 깨지 않는다.
3. 약 봉투 번호는 가장 강한 식별자이며, 색은 보조 단서다. 각 약 항목에 숫자와 약명을 함께 쓴다.
4. 아이콘은 모두 자체 SVG로 만들고 `아이콘 + 숫자 또는 짧은 라벨` 계약을 지킨다.
5. 약명, 용량, 단위, 식사 관계, 기간은 잘라내지 않는다. 정보가 많으면 장식을 줄이고 세로로 확장한다.
6. 힌디 본문은 `lang="hi"`, 행간 1.6 이상, 충분한 상하 여백을 사용한다. `word-break: break-all`과 문자 간격 조작을 금지한다.
7. 320px에서 한 열을 유지하고 표·가로 스크롤을 쓰지 않는다. 터치 동작은 최소 48px로 한다.
8. `½ 정`, ml, 캡슐, 점안액, PRN은 서로 다른 텍스트 단위를 보존한다. ml는 계량컵·주사기 등 보정된 도구를 안내한다.
9. 핵심 정보와 언어 전환은 최소 스크립트로 동작하되, 스크립트가 없어도 서버가 렌더링한 복약 내용은 모두 보인다.
10. 데모 처방에는 실제 권고가 아니라는 표시를 두고, 특정 정부기관·병원·약국의 승인이나 제휴를 암시하지 않는다.

## 현지 검증 필요

- `दोपहर`(정오/점심), `शाम`(저녁), `रात`(밤), `सोने से पहले`(취침 전)의 구분이 북인도 힌디 사용자에게 복약 시점으로 충분히 명확한가
- 접시와 알약의 좌우·상하 순서가 식전/식후로 해석되는가, 짧은 설명 후에도 기억되는가
