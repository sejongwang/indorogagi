Rive 테스트 벤치 — rive.app에서 export한 .riv를 드래그하면 즉시 재생 · 입력(파라미터) 라이브 주입
.riv 파일을 여기로 드래그 (또는 클릭해서 선택)
런타임 동작 확인용:
스테이트 머신 입력 (파라미터 슬롯) — 값을 바꾸면 즉시 반영
텍스트 런 치환 테스트 (규약: 숫자 자리 이름 n_*)

Rive 제작 규약 (indoro 씬) — ① 아트보드 360×300 ② 스테이트 머신 이름 scene (Entry→재생, 끝나면 정지 상태 = 정보 완결 프레임) ③ 숫자 파라미터는 Number 입력 n_*(예: n_days, n_qty_m), 변형 스위치는 Boolean v_*(예: v_chronic) ④ 화면에 보이는 숫자는 텍스트 런 이름 n_*로 — 코드가 실데이터 주입 ⑤ 스테이지 내 언어 0(숫자만) ⑥ 이미지 임베드 금지(벡터만), 파일 목표 씬당 ≤100KB ⑦ 금지 표현 = 빨간 슬래시.

무게 회계 (실측 gzip) — Rive 런타임 JS 35KB + WASM 445KB = ~480KB + 씬 .riv 수십 KB. 환자 첫 페인트는 0바이트(▶ 탭 후 lazy-load, 이후 캐시)지만 2G 첫 탭에서는 수십 초가 될 수 있음 — 이 트레이드오프는 팀 판정 사안. 카운터 태블릿은 로컬이라 무관. 참고: Lottie 경로는 77KB.
