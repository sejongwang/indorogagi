무언어 모션 프로토타입 — 스테이지 안 문자 0 (숫자 허용) · 녹음 없음 · 데이터 구동 시퀀서

샷 순서(항목 루프 × N + 코다 + 착지) — ① 식별: 봉투번호→알약 ② 하루: 슬롯 차례에 밥→약 사건 순서로 식전후 표현 ③ 기간: 점 채우기(완주=깃발 / 만성=약국 순환) ④ 주의: 슬래시 칩 ⑤ 코다: follow_up(달력 플립→의사 / 리필 루프) ⑥ 착지: 정적 매트릭스와 동일 구도로 정지 — 영상이 "정적 화면 읽는 법"을 가르치고 끝난다.

판정 포인트 — 진행 바 세그먼트를 눌러 해당 샷으로 점프. 언어 0 상태에서 각 샷의 의미가 복원되는가(특히: 식후=밥 먼저, 완주=웃어도 계속, 만성=끝없음 루프, PRN=시계 반 바퀴 후에만).
