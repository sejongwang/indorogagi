관통 데모 — B1 코어 (P1 → P3 → S1)

데모 시나리오: P1에서 FX-A 3항목 입력 → "확인하고 발급"(P2 시트) → P3 QR 제시 → 환자 폰에서 S1 열람. QR은 placeholder이므로 데모에서는 아래 카드 링크로 S1에 진입한다(D7 리허설만 LAN 실QR 옵션).

JS 비활성 검증: 브라우저에서 JS 끄고 열람 — 전 정보·언어 전환(?lang 링크)·공유(wa.me)가 성립해야 함(수용 기준).

상태 스위처 사용법

  • ?state=인벤토리 "상태 변형" 전환. 미등록 값은 기본 상태로 폴백.
  • ?lang=hi|en환자측 언어 토글(html[lang] CSS 토글). 약사측 UI는 영어 고정.
  • ?fx=a|b|c공용 픽스처(shared/fixtures.js): A=일상 3항목 · B=전 패턴 10항목 · C=엣지.
  • ?color=0항목 배지 hue 오프 — "색은 보조 부호, 숫자가 정본" 그레이스케일 검증.

각 화면 우상단의 빗금 개발 툴바(제품 아님)에서도 동일 전환 가능. 파라미터는 조합 가능(예: ?fx=c&lang=en&color=0).
