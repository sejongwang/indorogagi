# B1 리뷰 주석 — 관통 코어 (P1+P2 · P3 · S1 · index)

> **이 파일이 수정 백로그의 정본이다.** Claude Code가 이 파일을 직접 읽어 일괄 반영한다 —
> 팀 메신저는 알림·일정 조율용으로만 (docs/04 §2.2).

## 리뷰 라운드 규칙 (요약 — 정본 docs/04 §2.2)

- **오너**: 정영민 CPO — 수용 기준(docs/04 §3) 판정권 + sign-off 권한.
- **라운드 1**: 배치 생성 후 24시간 내, 동기 30분 — `index.html` 허브로 클릭 워크스루, **폰 실기기 1대 필수**.
- **반영**: Claude가 주석을 당일 일괄 수정·재배포.
- **라운드 2**: 비동기 체크리스트 confirm, 24시간 내.
- **라운드 상한 2** — 초과 쟁점은 아래 "이월" 섹션에 "디자인 단계 이슈"로 기록하고 배치는 확정한다(일정 보호).
- **주석 형식**: `- [ ] 화면ID/요소: 문제 — 수정 지시`
  - 예: `- [ ] P1/용량 스테퍼: 터치 영역 40px — 48px 이상으로`
  - 리뷰 시 인벤토리 "핵심 요소와 바인딩" 표를 체크리스트로 사용해 **요소 누락 0**을 대조.
- **확정**: 수용 기준 전 항목 통과 + CPO sign-off → 이 파일 하단에 확정 선언 → 파일 동결 + git 태그.
